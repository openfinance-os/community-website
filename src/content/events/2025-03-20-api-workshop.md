This hands-on workshop will guide you through the technical aspects of integrating with UAE Open Finance APIs.

## What You'll Learn

- Setting up OAuth 2.0 with PKCE for secure authentication
- Implementing consent flows and managing customer authorizations
- Making your first Account Information API calls
- Handling errors and edge cases
- Best practices for production deployments

## Prerequisites

- Basic understanding of REST APIs
- Laptop with Node.js or Python installed
- Sandbox credentials from Al Tareq (we'll help you get these)

## Schedule

**Morning Session (9:00 AM - 12:00 PM)**
- Introduction to UAE Open Finance architecture
- OAuth 2.0 and FAPI security deep-dive
- Hands-on: Setting up authentication

**Lunch Break (12:00 PM - 1:00 PM)**

**Afternoon Session (1:00 PM - 4:00 PM)**
- Consent management implementation
- Account Information API walkthrough
- Hands-on: Building a simple account aggregator
- Q&A and troubleshooting

## Bring

- Laptop with development environment
- Questions and use cases from your projects
