## The registry

**12** of **28** production directory registrations publish an active authorization server with an issuer. This is published metadata, not verified service availability or traffic.

4 registry changes this week:

- **19 Oct** — Zurich joined the production registry (LFI)
- **15 Oct** — Mercury added a role (Cert_Management)
- **15 Oct** — Emirates NBD had additional API families first observed (collection coverage can change) (atm)
- **15 Oct** — Emirates NBD had resource declarations change (observation, not deployment evidence) (Before: accounts v2.1; certification=Self-Certified; complete=false | accounts v2.1; certification=Self-Certified; complete=false | cop v2.1; certification=Self-Certified; complete=true | cop v2.1; certification=Self-Certified; complete=true | payments v2.1; certification=Self-Certified; complete=false | payments v2.1; certification=Self-Certified; complete=false | products v2.1; certification=Self-Certified; complete=true | products v2.1; certification=Self-Certified; complete=true. ## Ecosystem activity

Ecosystem Watch observation: **2026-10-09**; source data through **2026-10-07**.

- **1,416,887** cumulative API calls across 2025-11 through 2026-09 (excluding partial 2026-10)
- Payment success **95.3%** and API error rate **18.4%**, across completed months
- **16** LFIs and **17** TPPs with successful traffic in the source's last two completed months

These are cumulative and period-based measures, not activity during the digest week. Changes between observation totals are not reported as weekly growth.
