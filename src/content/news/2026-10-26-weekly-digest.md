Our weekly read on the UAE Open Finance ecosystem, drawn straight from the [Observatory](/observatory) and the [Ecosystem Watch](/observatory/watch/). Every figure below is computed from public data — the trust-framework directory and the Al Tareq platform's own logs — with our [methodology](/observatory/methodology) in the open.

## The registry

**12** of **29** production directory registrations publish an active authorization server with an issuer. This is published metadata, not verified service availability or traffic.

3 registry changes this week:

- **21 Oct** — EIB added a role (LFI)
- **20 Oct** — EIB joined the production registry
- **19 Oct** — Zurich joined the production registry (LFI)

## Ecosystem activity

Ecosystem Watch observation: **2026-10-26**; source data through **2026-10-21**.

- **1,416,887** cumulative API calls across 2025-11 through 2026-09 (excluding partial 2026-10)
- Payment success **95.3%** and API error rate **18.4%**, across completed months
- **16** LFIs and **17** TPPs with successful traffic in the source's last two completed months

These are cumulative and period-based measures, not activity during the digest week. Changes between observation totals are not reported as weekly growth.
