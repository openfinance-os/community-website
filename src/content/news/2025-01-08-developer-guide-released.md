The OpenFinance-OS community has released a comprehensive developer guide to help TPPs and banks integrate with the UAE Open Finance ecosystem.

## What's Included

The guide covers essential topics for developers:

### Getting Started
- Overview of the UAE Open Finance architecture
- Step-by-step sandbox onboarding
- Development environment setup

### Authentication Deep-Dive
- OAuth 2.0 with PKCE implementation
- FAPI security profile requirements
- Certificate management

### API Integration
- Account Information API walkthrough
- Payment Initiation implementation
- Error handling patterns

### Best Practices
- Security recommendations
- Performance optimization
- Production deployment checklist

## Community Contribution

This guide was created by community contributors based on real-world implementation experience. It complements the official Al Tareq documentation with practical insights and code examples.

## Access the Guide

The guide is available on the [Learn](/learn) section of this website. We welcome feedback and contributions via GitHub.
