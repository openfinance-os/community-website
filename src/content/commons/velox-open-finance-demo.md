## Overview

Velox is an interactive demonstration platform that brings the UAE Open Finance ecosystem to life. Named after the Latin word for "swift," it provides instant access to explore Open Finance concepts, API structures, and ecosystem data without any setup required.

## Features

- **Live Ecosystem Data** — View real participant information from the Trust Framework Directory
- **Interactive API Explorer** — Understand request/response structures for Account Information and Payment Initiation APIs
- **Consent Flow Visualization** — Step through the customer authorization journey
- **No Credentials Required** — Explore immediately without sandbox registration

## Who Is This For?

### Developers
Get familiar with Open Finance API structures before diving into sandbox integration. Understand the data models, authentication flows, and error handling patterns.

### Product Managers
Visualize the customer experience and understand what's possible with Open Finance data access.

### Bank Teams
See how TPP integrations work from the TPP perspective, helping inform your API implementation decisions.

### Curious Observers
Anyone interested in understanding how Open Finance works in practice.
